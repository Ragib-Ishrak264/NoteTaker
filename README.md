# Notes Web Application

A clean, responsive, local-first note-taking web application with rich text formatting, sketch / canvas drawing tools, PDF annotation, tags, folders, and export options.

## Deployment on Vercel

This is a pure static web application and is configured for deployment on [Vercel](https://vercel.com).

1. Push this repository to GitHub.
2. In Vercel, import the repository (`Ragib-Ishrak264/NoteTaker`).
3. Set Framework Preset to **Other** (default).
4. Deploy!

## Local Development

To run locally in a browser:
```bash
node local-server.js
```
or run `start.bat`.
Open [http://localhost:8000](http://localhost:8000) in your web browser.
